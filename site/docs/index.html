New here? Start with one push.

The quickstart takes a Linux server, a domain, and Docker only if you need containers. It ends with a public URL. If you only read one page, read that one.

Open the quickstart
bash
curl -fsSL https://dok.djt-group.com/install.sh | sh
read -rs DOK_TOKEN && export DOK_TOKEN
dok login https://dok.example.com
dok push ./my-app --app my-app
